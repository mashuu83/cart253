For my first prototype this week I wanted to expand upon my 5000 cube drawing from last week, encouraging the user to use the camera controls to explore the work. My idea for the prototype was to have all the cubes rotate except a single one rotating the oppoiste direction, encouraging the user to explore by giving them a goal to look for. I originally struggled a lot trying to define a single cube out of the 5000 so I could address it individually, I ended up using a different method (just choosing the cube halfway through the loop instead of a random cube in the loop, the end effect is the same since every cube is randomply positioned anyway, I could have also done the first or last cube, on reflection, which might be even simpler). Once I was able to address a single cube, I tried a few variations of rotation style (all cubes move around a central axis, cubes rotate on their own axis, cubes all start at the same roation and rotate together...) all of the variants were visually interesting in different ways and it was fun to try different combinations.
